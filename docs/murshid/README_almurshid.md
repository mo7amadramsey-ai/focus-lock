# المرشد الدراسي (Al-Murshid)

تطبيق أندرويد يسجّل دخولك إلى مودل جامعة UCAS مرة واحدة، ثم يقرأ **كل المواد ومحتوياتها بالتوازي** ويحفظ الشجرة على الهاتف (بدون خادم). الهوية: بني فاتح + بيج + زيتي هادئ.

## المراحل
1. **(مبنية، لم تُجرَّب على الهاتف)** الدخول + الزاحف المتوازي + عرض الشجرة.
2. عرض وتصنيف أفضل للمحتوى.
3. الجدول الدراسي (الخوارزمية القديمة في مستودع focus-mentor، فرع `focus-lock-legacy`: `lib/planner/`).
4. القفل الصارم كإضافة (الكود القديم في الفرع نفسه).

## البناء
كل push يشغّل الاختبارات ثم يبني APK ويرفعه في **Releases**.
عند الفشل اقرأ فرع `buildlog` (`errors.txt`).

انظر `HANDOFF.md`.
