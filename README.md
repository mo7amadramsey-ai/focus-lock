# Focus Lock

تطبيق أندرويد للدراسة بدون تشتت:
- متصفح مقيّد بيوتيوب فقط (أي نطاق آخر محظور).
- تحميل الفيديوهات داخل التطبيق ومشاهدتها لاحقاً.
- **الوضع الصارم**: المؤقت = مدة الفيديو، يُحفظ بوقت النهاية الحقيقي، لا يتأثر بالتقديم/التأخير، ولا يوجد أي زر خروج. يستمر حتى لو أُغلق التطبيق أو أُعيد تشغيل الهاتف.
- أثناء القفل: تشغيل/إيقاف، ±10 ثوانٍ، والرد على المكالمات فقط.

## البناء
كل push يبني APK تلقائياً عبر GitHub Actions: تبويب **Actions** ← آخر تشغيل ← **focus-lock-apk**.

## تفعيل القفل (من الهاتف فقط)
عند أول ضغط على "الوضع الصارم" يطلب التطبيق تفعيل خدمة **Focus Lock** من إعدادات إمكانية الوصول.
- على أندرويد 13+: معلومات التطبيق ← ⋮ ← **السماح بالإعدادات المقيدة**، ثم فعّل الخدمة.
- أثناء الجلسة تعيدك الخدمة للتطبيق فوراً إن حاولت فتح الرئيسية أو الإعدادات أو أي تطبيق آخر، وتبقى فعالة بعد إعادة التشغيل.
- (اختياري) للقفل الأقوى عبر Device Owner: `adb shell dpm set-device-owner com.mohammed.focus_lock/.FocusAdmin`
